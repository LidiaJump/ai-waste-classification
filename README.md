# AI 视觉赋能下的垃圾识别分类科普系统

**桂电智眼分类引擎 · 2025 睿抗机器人开发者大赛 AI 视觉应用赛项目**

本项目面向校园垃圾分类与环保科普场景，以 **YOLOv11n** 为视觉识别核心，将图片检测、摄像头实时检测与分类知识学习结合起来。用户可以查看垃圾目标的位置、名称、置信度和分类建议，也可以通过互动答题与本地 AI 问答学习相关知识，并回看历史检测记录。

系统采用 Python、PyQt5、OpenCV 和 PyTorch 构建桌面应用，围绕轻量化部署、检测稳定性与交互易用性进行设计，可用于校园课堂、环保宣传和垃圾分类演示。

> 本仓库用于项目展示与资料归档，包含 PPT、演示视频、项目报告和设计文档。应用源码、模型权重及训练数据集尚未收录。

## 核心功能

| 功能模块 | 主要能力 |
| --- | --- |
| 识别检测 | 支持本地 PNG/JPG 图片与摄像头画面检测，展示目标框、中英文名称、所属垃圾类别、置信度及处理建议；支持调整置信度阈值和查看分类统计。 |
| 互动答题 | 通过垃圾分类知识题目开展交互式学习，面向校园科普与环保教育场景。 |
| AI 问答助手 | 接入本地大模型，围绕垃圾类别、处理方式和投放注意事项提供知识问答。 |
| 检测历史与结果保存 | 通过 MySQL 保存检测记录，支持历史回看；检测模块提供手动保存、自动保存及 JSON/TXT 报告导出。 |

## 设计亮点

- **轻量化检测模型**：采用 YOLOv11n，兼顾目标识别能力与设备资源开销，面向本地部署场景。
- **多线程处理**：将采集、推理等耗时任务与界面交互分离，减少检测过程中的界面阻塞。
- **多帧稳定性判断**：结合帧缓存、边界框匹配与历史结果一致性过滤，缓解单帧误检和结果抖动。
- **针对类别不均衡的训练优化**：项目训练方案引入类别权重及类似 Focal Loss 的调制思路，加强对少数类别和难分样本的关注。
- **识别与科普结合**：识别结果提供分类建议，问答和答题模块帮助用户进一步理解垃圾分类知识。

## 技术方案

视觉检测流程包括图像采集、预处理、模型推理、结果稳定性过滤和界面展示。系统通过保持宽高比缩放与边缘填充处理输入图像，再将检测结果映射为垃圾分类信息和处理建议，供用户查看、保存或导出。

| 技术 | 在项目中的用途 |
| --- | --- |
| Python / PyQt5 | 桌面应用、界面交互与工作线程管理 |
| Ultralytics YOLOv11n / PyTorch | 目标检测、模型训练与推理；在可用环境下使用 CUDA 加速 |
| OpenCV | 摄像头采集、图像处理和检测结果绘制 |
| Albumentations | 旋转、翻转、亮度变化、噪声等数据增强 |
| Adam / 自定义损失计算 | 模型优化与类别不均衡处理 |
| MLflow | 训练参数、评估指标和模型产物记录 |
| MySQL | 检测历史记录存储 |
| 本地大模型 | 垃圾分类知识问答 |

技术设计详见[项目报告](4.%E9%A1%B9%E7%9B%AE%E6%8A%A5%E5%91%8A%EF%BC%9AAI%E8%B5%8B%E8%83%BD%E4%B8%8B%E7%9A%84%E8%BD%BB%E9%87%8F%E5%8C%96%E5%B8%B8%E8%A7%81%E5%9E%83%E5%9C%BE%E8%AF%86%E5%88%AB%E5%88%86%E7%B1%BB%E7%B3%BB%E7%BB%9F.docx)与[项目设计文档](5.%E9%A1%B9%E7%9B%AE%E8%AE%BE%E8%AE%A1%E6%96%87%E6%A1%A3.pdf)。

## 训练与实验记录

以下信息整理自项目 PPT 的“训练过程”页面：

| 项目 | 材料记录 |
| --- | --- |
| 基础模型 | YOLOv11n |
| 数据规模 | 约 6,000 张图像，覆盖 8 类垃圾目标 |
| 部分类别 | 塑料瓶、塑料袋、易拉罐、废纸、纸箱、电池等 |
| 训练轮次 | 150 轮 |
| 优化器 | Adam |
| 整体 mAP@0.5 | **94.1%** |

mAP@0.5 是 IoU 阈值为 0.5 时的目标检测评估指标。上述数值为项目材料记录的测试集结果；复现实验需要结合对应的数据划分、模型权重与评估配置。

项目报告还记录了图片检测、摄像头检测、置信度调整、结果保存、统计导出及异常输入处理等功能测试。

## 应用场景与后续方向

项目主要面向校园垃圾分类教学、环保主题活动和现场交互演示，也可作为社区科普与人工智能视觉课程的实践案例。

后续计划继续扩充垃圾类别和复杂场景样本，完善不同设备上的部署与性能评估，并探索与分拣硬件连接。自动分拣、回收处理等硬件能力属于后续拓展方向。

## 获取完整文件

PPT 与演示视频通过 **Git LFS** 存储。安装 Git 和 Git LFS 后，可以执行：

```bash
git lfs install
git clone https://github.com/LidiaJump/ai-waste-classification.git
cd ai-waste-classification
git lfs pull
```

若下载的 PPT 或视频只有几行文本，说明拿到的是 LFS 指针文件，需要获取对应的大文件内容。仓库当前用于资料浏览，运行完整应用还需配套源码、模型权重与环境配置。
